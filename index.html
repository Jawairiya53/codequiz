    About CodeQuiz

    CodeQuiz is a front-end project built with plain HTML, CSS and JavaScript. It has a configurable quiz setup, a per-question timer, live scoring, answer review and saved history.

    Questions live in questions.js. Add a new topic there and it appears on the Home screen automatically.
